# JobTracker — Job Application and Interview Tracker with Analytics

JobTracker is a responsive web application that helps users organize job applications, track interview schedules, monitor application statuses, and visualize job-search progress through an analytics dashboard.

## Features

- **Dashboard:** View total applications and application status counts.
- **Application Management:** Add, edit, and delete job application records.
- **Interview Tracking:** Record interview dates and preparation notes.
- **Upcoming Interviews:** View scheduled interviews in date order.
- **Search, Filter, and Sort:** Find and organize applications easily.
- **Analytics Dashboard:** Visualize application statuses and track interview and selection rates.
- **Form Validation:** Validate required fields, dates, and duplicate applications.
- **Local Storage:** Keep application records saved in the browser.
- **CSV Export:** Export application data for external use.
- **Responsive Design:** Use the application on desktop and mobile screens.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser LocalStorage

## Getting Started

1. Clone or download this repository.
2. Open `index.html` in a web browser.
3. Start adding and managing job applications.

An internet connection is required to load Chart.js from its CDN.

## Data Storage

Application records are stored locally in the browser using LocalStorage. Data does not automatically synchronize between different browsers or devices.
